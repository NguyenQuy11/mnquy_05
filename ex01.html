INTRODUCTION TO HTML

  1. Overview

    HTML, short for Hyper Text Markup Language, is the standard markup language for creating web pages.

    HTML describes the structure and meaning of content. CSS controls its layout and appearance. A browser reads the HTML document and displays it as a web page.
